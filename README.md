# To Do — Beginner Django App
A tiny beginner-friendly Django app showing basic CRUD with class-based views and simple Bootstrap styling.

## Quick start
```bash
python -m venv venv
venv\Scripts\activate
pip install django
python manage.py migrate
python manage.py runserver
```
### Features
List, add, edit, view, delete tasks
Bootstrap CDN + small custom CSS
Simple templates for learning
